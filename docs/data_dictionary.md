| Field | Meaning |

| Housing | Own, rent, or free housing |
| Saving accounts | Savings-status band |
| Checking account | Checking-status band |
| Credit amount | Requested credit amount in DM |
| Duration | Loan duration in months |
| Purpose | Stated credit purpose |
| credit_risk | 1 = bad/risky; 0 = good |
